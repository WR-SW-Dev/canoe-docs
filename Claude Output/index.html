How to read them

Two tracks, run in parallel

A and B are independent workstreams. They share the Canoe feed and the archive, but neither depends on the other — so they can be designed and built at the same time.

Track A — Statement Tracker

GenAI: none (v1) · Gate: none (v1)

Complements today's manual process — cuts the tracking burden and time spent, without taking the sheet away. Fully compliant out of the gate — nothing to approve to start. The low-risk, high-value first build.

Track B — Intelligence Layer

GenAI: extraction + RAG · Gate: LLM access path

Higher-value, but gated on a compliance decision. Kick off the IT Lead/CTO review in parallel with building A, so B isn't waiting on a review that never started.

The decision that gates Track B (and A's v2)

LP statements are financial-account and portfolio-detail documents, which the Gen AI policy restricts to M365 Copilot within the licensed environment. Sending statement text to any other model needs an IT Lead/CTO review via the policy's "request a review of a new LLM" path — an authorization call, not an engineering one. Full detail in the intelligence-layer gate.
