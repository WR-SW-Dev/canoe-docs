Fetching an Access Token via Python
Each call to the Canoe API must include an access token in the headers of the request.
You must first fetch an access token via password grant or Oauth client credentials. Once
the access token has been retrieved, it should be added to your headers and included in all
subsequent requests.
import requests
headers = {
  'Accept": 'application/json',
  'X-Requested-With": 'XMLHttpRequest',
  'Content-Type": 'application/json'
}
