Canoe’s API supports a wide array of use cases, including retrieving data extracted from
documents,
downloading documents from Canoe, uploading documents, and managing ownership

Funds, Allocations, etc.). See our full API documentation for detailed explanations of API

Why Use Canoe's API?
Canoe's API offers significant advantages over traditional data delivery methods like
SFTP/FTPS or
manual downloads, regardless of portfolio size:
1. Automation & Real-Time Access: The API enables full automation of data ingestion.
This
means programmatic data retrieval whenever needed, including near real-time updates
for critical
information like ownership changes, new document availability, and more. This
eliminates manual
effort and ensures your systems are always current.

frequencies, the
API scales to meet your needs, whether you manage a few funds or thousands. It also

Postman Collection
In addition to the bash, JavaScript, php, python, and C# examples next to each endpoint,
we’ve also
included a Postman collection. The collection contains API calls for each available endpoint.
Postman is a tool that helps generate and test API calls by providing a clean interface to
build and
save HTTP requests, and to check and test API responses.
You may download the Postman collection here.  Note: the collection was last updated on
January 25, 2024. If you are looking for a more recent version, please reach out to our
support team.
Rate Limits
Canoe's standard rate limits are 60 calls per minute per access method (GET, POST, PUT,
DELETE).  Note that these limits are not based on the endpoint.

IP Whitelisting
Your information security team may require whitelisting Canoe’s IP addresses before
you can call the API.  Whitelist this address to allow all API addresses of
Canoe: outgoing-ips.prod.canoesoftware.com
Your information technology team may require you to open ports to call the API.  The
API uses port numbers 443 and 9443.
Additionally, your information security team may request that Canoe limit the IP
address(es) from which you can make API calls as an extra layer of data protection.  If
so, please reach out to our support team.
